# مقایسهٔ دو پروفایل ارائه‌شده توسط کاربر

تاریخ بررسی: ۲۰۲۶/۱۱/۰۱. بررسی ایستا، بدون نصب، بدون اجرای محتوای فایل و بدون تماس با سرویس فروشنده انجام شد. فایل‌های اصلی و محتوای رضایت در مخزن کپی نشده‌اند.

## ساختار مؤثر

| ویژگی | نمونهٔ همراه اول | نمونهٔ ایرانسل |
|---|---|---|
| تعداد payload | ۱ | ۱ |
| نوع | com.apple.cellular | com.apple.cellular |
| APN | mcinet | mtnirancell |
| AuthenticationType | PAP | PAP |
| نام کاربری و رمز APN | وجود ندارد | وجود ندارد |
| AllowedProtocolMask | ۳، IPv4 و IPv6 | ۱، فقط IPv4 |
| ماسک رومینگ داخلی و بین‌المللی | ۳ | ۱ |
| EnableXLAT464 | false | false |
| AttachAPN | وجود ندارد | mtnirancell، PAP، ماسک ۱ |
| VPN، MDM، پروکسی، DNS یا گواهی ریشه به‌عنوان payload | وجود ندارد | وجود ندارد |

نمونه‌ای که برای همراه اول و حالت دوسیم معرفی شده، فقط یک APN با مقدار mcinet دارد. از محتوای آن نمی‌توان پشتیبانی مستقل از هر دو سیم یا APN ایرانسل را نتیجه گرفت. طبق مرجع Cellular اپل، تنظیمات بر سیم‌کارت منتخب داده اعمال می‌شوند.

## امضا و محدودیت دستگاه

هر دو فایل CMS امضاشده‌اند. OpenSSL با cms -verify -noverify، صحت ریاضی امضا و یکپارچگی محتوای هر دو را تأیید کرد؛ این فرمان اعتماد زنجیره را بررسی نمی‌کند.

هر دو همان یک گواهی خودامضا را در CMS دارند؛ خودامضا بودن با بررسی امضای گواهی توسط کلید عمومی همان گواهی نیز تأیید شد. اعتبار زمانی گواهی از ۱۵ مه ۲۰۲۶ تا ۱۵ مه ۲۰۲۷ است. این موضوع به‌تنهایی به معنی اعتماد عمومی iOS یا گواهی تجاری نیست.

محتوای plist رمزگذاری نشده است. کلیدهای هدف‌گیری دستگاه در ریشه، payload مربوط به MDM، و سازوکار قابل مشاهدهٔ اتصال به سخت‌افزار در این دو فایل وجود ندارد. UUID پروفایل، شناسهٔ سخت‌افزار گوشی نیست. امضای CMS به‌تنهایی فایل را به یک دستگاه قفل نمی‌کند. محدودیت احتمالی دانلود در سمت سایت از روی این فایل‌ها قابل تشخیص نیست.

## متن شبیه کد

هر دو فایل دقیقاً یک رشتهٔ ۱۲٬۰۷۲ کاراکتری شبیه کد پایتون در ConsentText.default دارند. نام‌هایی مانند generate_device_identifier، generate_neighbors، snapshot و signal_quality در آن دیده می‌شود. این فیلد متن رضایت است؛ iOS آن را به‌عنوان پایتون اجرا نمی‌کند. این متن سازوکار تغییر IMEI، انتخاب باند یا تغییر سلول شبکه محسوب نمی‌شود. کد اجرا یا در پروژه استفاده نشده است.

## تفاوت با پیش‌فرض فعلی پروژه

- همراه اول پروژه: CHAP، نام کاربری و رمز mcinet، AttachAPN روشن و 464XLAT روشن. نمونهٔ ارائه‌شده: PAP، بدون اطلاعات ورود، AttachAPN غایب و 464XLAT خاموش.
- ایرانسل پروژه: هر دو پروتکل و 464XLAT روشن. نمونهٔ ارائه‌شده: فقط IPv4 و 464XLAT خاموش. AttachAPN در هر دو وجود دارد.

این تفاوت‌ها گزینه‌های مشخصی برای آزمایش مقایسه‌ای هستند؛ اثبات علت موفقیت یا تأیید APN با سیم‌کارت واقعی نیستند. در این بررسی اتصال واقعی هیچ گوشی آزمایش نشده است و ادعای کارکرد نمونه بر پایهٔ گزارش ارائه‌دهنده باقی می‌ماند.

برای آزمایش بعدی، باید دستگاه، سیم‌کارت و شرایط ثابت بمانند؛ پروفایل آزمایشی قبلی حذف شود، هر بار یک پارامتر تغییر کند و نصب، بازگشت داده/آنتن و زمان افتادن جدا ثبت شوند. امضا و متن رضایت به‌عنوان پارامترهای رادیویی تفسیر نشوند.
